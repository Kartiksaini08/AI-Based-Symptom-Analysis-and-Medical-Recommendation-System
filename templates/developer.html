Developer note

The project evolved beyond a classroom demo.

What started as a machine learning symptom classifier has been improved into a more complete product-style application. The work now includes modular Flask architecture, a reproducible training pipeline, structured inference artifacts, validation for symptom entry, and a redesigned interface focused on clarity and safety messaging.

The build emphasizes not just whether a model can predict, but whether the output is understandable, actionable, and presented responsibly.
