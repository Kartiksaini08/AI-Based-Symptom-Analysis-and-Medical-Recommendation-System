Build story

From a simple predictor to a guided health UX project.

This project started as a symptom-based disease classifier and evolved into a more complete experience with guided symptom input, top-match predictions, and practical care guidance.

Project overview

What problem are we solving?

People often know how they feel, but struggle to translate those symptoms into structured information. This project was built to bridge that gap. Instead of relying on raw text alone, the current version uses a guided symptom picker, model-backed predictions, and clear recommendation cards.

How the app works

1. Symptom selection

Users choose supported symptoms with autocomplete and chip-based selection.

2. Prediction pipeline

A rebuilt training pipeline compares multiple models and exports a fresh inference bundle.

3. Top match output

The app shows the most likely condition plus alternative matches with confidence values.

4. Actionable guidance

Users receive precautions, diet support, medicines, activity tips, and care escalation cues.

Why this version is stronger

The current implementation is more than a model demo. It now has a modular backend, reproducible training script, improved validation, structured result presentation, and UI decisions that reduce input errors and make the result easier to act on.

Stack highlights

Flask backend

Handles routing, validation, prediction, and template rendering.

scikit-learn models

Compared with a reproducible training script and saved as a joblib bundle.

Dataset-driven guidance

Precautions, medications, workouts, and diet advice come from linked CSV resources.

UX-focused frontend

Autocomplete chips, inline results, urgency color coding, and matched symptom highlighting.
